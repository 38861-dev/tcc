# R.tual Hair Care

Este projeto foi criado para apresentar o R.tual Hair Care de forma simples, bonita e acolhedora.

Aqui, os clientes podem conhecer o salão, consultar os serviços disponíveis e realizar um agendamento.

## Acessos de demonstração

O botão **Login** na página inicial abre a tela de acesso para cliente e administrador. O login do cliente é apenas visual e informa que a autenticação depende da integração com o backend; não valida nem armazena credenciais. O painel administrativo usa os agendamentos deste navegador como demonstração e também não possui autenticação real.
